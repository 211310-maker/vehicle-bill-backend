## PDF download server
1. Place sample or real PDFs in `./pdfs/` (e.g., `./pdfs/69368b7b684539e08eb01077.pdf`).
2. Start the server: `node server.js` (uses port `4000` by default).
3. From the frontend, request `http://localhost:4000/bill/69368b7b684539e08eb01077/pdf` (or your deployed backend URL) to trigger the auto-download flow.
